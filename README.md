## ✨ Despre Proiect

**Sweet Cakes by Gabriella** este o experiență digitală premium creată pentru un atelier artizanal de cofetărie. Site-ul pune accent pe eleganță, detalii vizuale rafinate și o experiență de utilizare (UX) de tip boutique.

## 🌟 Caracteristici Cheie

- **🎨 Design Boutique Luxury:** O estetică minimalistă și sofisticată, folosind o paletă de culori crem, antracit și magenta.
- **🚀 Premium Loading Experience:** Ecran de încărcare personalizat care reflectă identitatea brandului.
- **📅 Custom Date Picker:** Calendar artizanal construit de la zero pentru o experiență de rezervare fără cusur.
- **♿ Meniu de Accesibilitate:** Control total asupra contrastului, dimensiunii textului și animațiilor pentru toți utilizatorii.
- **📱 WhatsApp Integration:** Buton de contact direct cu mesaje pre-completate.
- **📜 Istoric Comenzi:** Sistem de memorare locală a cererilor anterioare (Local Storage).

## 🛠️ Tehnologii Utilizate

- **Frontend:** React.js, TypeScript
- **Stilizare:** Tailwind CSS (configurație custom pentru culori brand)
- **Animații:** Framer Motion (paralaxă, springs, layout transitions)
- **Icons:** Lucide React
- **Build Tool:** Vite
- **Backend:** Node.js
